# dotfiles

同梱しているプラグイン等はそれぞれのライセンスに従う。
その他 74th 作成のスクリプト等については、MIT ライセンスとする。

## 使っているツール類

### package manager

- ubuntu
- homebrew
- cargo
- go
- pip

## super-update

`super-update claude codex` は、未導入ならインストールし、導入済みなら更新する。
`super-update openspec` で OpenSpec をインストールまたは更新する。
Volta が未導入の場合は、先に Volta と Node.js をインストールする。
`super-update volta` で Volta と Node.js を直接インストールまたは更新することもできる。
